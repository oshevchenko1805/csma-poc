## Суть и главные результаты
Три архитектуры: A — централизованная (один домен наземной станции), B — сегментированная без самовосстановления, C — CSMA с обменом между узлами (ZeroMQ) и самовосстановлением. Различия только через конфигурацию и DI, без `if architecture` в коде.
Рамка: какие данные может доверять каждый этап цикла самовосстановления (независимость от скомпрометированного узла и домен отказа).
- H1 (выявление при компрометации плоскости безопасности): отключение локальных детекторов — C 30/30 против A 0/28, B 0/30 (перекрёстная проверка в другом домене отказа); отключение домена мониторинга — B 29/30 и C 30/30 против A 0/28; контраст C–B нулевой.
- Подмена команды: C фильтрует, миссия 13/15 против 0/15.
- Атаки на ГНСС: ни одна архитектура не восстанавливает навигацию; LOITER даёт снос ≈50 м; парадокс: раннее выявление даёт худший результат.
- H2 (перевірочна кампанія, 131 прогон): удержание нулевой скорости вместо LOITER — медиана сноса 50.13 → 1.53 м и 50.12 → 1.44 м, p(Holm) = 3.7·10⁻⁶ и 3.4·10⁻⁶.
- H3 (20 полётов): проверка по межагентным дальностям закрывает слепую зону медленной подмены (1 м/с): 5/5, вред до тревоги ≤ 6.41 м при пороге 6.8 м, 0 ложных тревог; предел ≈ 6σ погрешности ГНСС (офлайн-карта).
- MTTD ≈ 2.9 с, из них 2.0 с — постоянная стенда (k = 3 при 1 Гц); MTTR и время до изоляции (≈52 мкс) архитектуру не различают.
- Основная кампания: 435 записей, 414 валидных (136/140/138).
- Новизна (3 пункта, без «вперше»): «набуло подальшого розвитку» — зависимость от независимости данных и домена отказа; «удосконалено» — выбор действия восстановления (H2); «удосконалено» — выявление по дальностям в цикле CSMA (H3).
