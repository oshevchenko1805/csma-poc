# P14: «Отже / Тому / Звідси» на початку речення — застосовано (-20 → -21_p14_starters.docx)

Джерело: -20_p13_ch4.docx. Правило STYLE_RULES §4: не більше одного такого початку на сторінку. Інвентар (розд. 1–4): 83 початки; сторінок з понад одним — 14. «Отже» в розд. 3 — 18.
Сторінки — за рендером LibreOffice (185 с.), орієнтовно (сторінка початку абзацу).
Принцип: «Отже» лишається там, де воно закриває підрозділ; в інших місцях слово прибирається або замінюється. Короткі речення не зливаються (рішення автора 29.09: короткі речення лишаються, частина 2 P14 скасована). «Тому/тобто/бо/оскільки» не додаються; «через це» — двічі.
